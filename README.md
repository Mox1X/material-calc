# material-calc

`material-calc` — самостоятельный набор инструментов для разработки технических модов Minecraft. Он помогает проектировать материалы и сплавы, сравнивать их расчётные свойства и готовить данные и текстуры для использования в модах.

## Возможности

- Расчёт свойств сплава по составу и условиям обработки и эксплуатации. Результат включает оценки твёрдости, коррозионной стойкости и тепловых свойств.
- Классификация элементов по формам предметов и генерация окрашенных иконок из шаблонов.
- Выгрузка расчётных свойств предопределённых марок сплавов в SQLite.

## Интеграция с модами

Ядро расчётов и обработка данных развиваются независимо от конкретного мода и загрузчика. Регистрация предметов и блоков выполняется на стороне мода, который использует подготовленные данные и ресурсы. В `reference/` хранятся справочные примеры интеграции.

Дальнейшая работа включает расширение расчётов и инструментов подготовки данных, исправление ошибок и добавление регрессионных проверок для исправленных случаев.

## Быстрый запуск

Из корня репозитория:

```sh
python3 alloy_cli.py --composition Fe:0.98,Cr:0.02 --pretty
python3 -m unittest discover
```

Структура кода и команды для разработчиков описаны в [AGENTS.md](AGENTS.md).

## Расчёт материалов

Состав передаётся как пары `элемент:массовая доля`. Например, `Fe:98,Cr:2` и `Fe:0.98,Cr:0.02` задают один состав. Для близких стехиометрических совпадений калькулятор использует справочную фазу как допущение. Для неоднозначных составов он показывает кандидатов и сообщает, какие свойства требуют дополнительных сведений.

Справочный профиль выбирается через `--material-profile ID` в CLI или через `edit-params` в TUI. Можно передать один профиль или дополнительно указать согласующийся с ним состав.

| ID профиля | Номинальные массовые доли |
|---|---|
| `alumina-zirconia-80-20` | 80% Al₂O₃ и 20% ZrO₂ |
| `zirconia-yttria-92-8` | 92% ZrO₂ и 8% Y₂O₃ |

```sh
python3 alloy_cli.py --composition Al:52.93,O:47.07 --pretty
python3 alloy_cli.py --material-profile alumina-zirconia-80-20 --pretty
```

Профили описывают исходную смесь оксидов. Расчёт плотности предполагает нулевую пористость и аддитивные объёмы фаз. Для свойств изделия после обработки нужны сведения о реальном фазовом составе и технологии.

## Формат отчёта v2

Верхний уровень содержит `schema_version: 2`, `status`, `composition_normalized`, `conditions`, `classification`, `feasibility`, `properties` и `diagnostics`. Потребители должны читать новый формат. Прежние отдельные секции расчёта заменены оценками в `properties` и деталями модели в `model_details`, когда они доступны.

| Статус | Значение | Код выхода CLI |
|---|---|---:|
| `ok` | Применима расчётная модель материала | 0 |
| `partial` | Часть свойств требует дополнительных данных | 0 |
| `unsupported` | Для состава нет применимой модели | 0 |
| `invalid` | Некорректный ввод | 2 |

У каждой доступной оценки есть `value`, `range`, `unit`, `method`, `source` и `assumptions`. `range` содержит границы при наличии применимого диапазона. Недоступное свойство равно `null`. Ликвидус, солидус, плавление и разложение или сублимация имеют отдельные поля. Индекс склонности к коррозии разработан как эвристика для указанной среды. Гальванический риск требует данных о контактирующем материале, электролите и контакте.

Старые сохранённые кейсы читаются в TUI. Для SQLite v2 создайте базу повторным экспортом из исходных составов. Если нужна старая база, укажите новый путь в `--db`, поскольку экспорт пересоздаёт таблицы по указанному адресу. В манифесте текстур сплава появились `material_status` и `color_source`. Текстуры можно получать и для составов со статусом `unsupported`.

Сводка сравнительного прогона доступна в [ALLOY_TEST_RESULTS.md](ALLOY_TEST_RESULTS.md).
